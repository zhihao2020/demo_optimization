# 风光 / 负荷日前信息结构

## 一句话

- **物理真值**：始终由 FMU 内嵌表驱动  
- **策略观测**：默认 **24h 完美日前**（`forecast.mode=perfect`）  
- **可选**：`noisy` 乘性误差；`predicted` residual BiLSTM（改进 24h persistence DA）  

这是 **price-taker 厂站调度下的日前预报**，**不是** ISO 出清或完整电力市场交易流程。

## 三级资源信息结构

| mode | 观测内容 | 训练/数据 |
|------|----------|-----------|
| `perfect` | CSV 真值 T+1…T+24 | 主表默认 |
| `noisy` | 真值 × (1+ε) | `noise.sigma` |
| `predicted` | residual BiLSTM 导出 CSV | persistence DA + 学残差 |

### P1-2 流水线

```powershell
$env:PYTHONPATH = "src"
python scripts/build_resource_residual_series.py
python scripts/train_resource_bilstm.py --epochs 25 --device cpu
# 产物：data/resource_predicted/*.csv
#       data/forecast_models/resource_bilstm.pt
```

定义：`realized`=CSV 真值；`DA`=24h persistence；`eps=realized-DA`；`pred=DA+eps_hat`。

## 配置

`src/config/env_config.yaml` → `forecast`：

| 字段 | 含义 |
|------|------|
| `mode` | `perfect` / `noisy` / `predicted` |
| `noise.sigma.*` | 各通道乘性相对误差标准差 |
| `predicted_sources` | BiLSTM 导出路径（物理单位） |

```python
PowerSystemEnv(forecast_mode="predicted")
PowerSystemEnv(forecast_mode="noisy", forecast_noise_seed=0, forecast_noise_sigma=0.10)
```

## 论文表述建议

> The agent observes a 24 h day-ahead forecast of wind, irradiance, temperature and load, while the FMU realizes physical trajectories. Main experiments use perfect forecasts. We also evaluate multiplicative forecast noise and a residual BiLSTM that improves upon 24 h persistence day-ahead baselines. Settlement always uses realized prices; we do not model ISO clearing.

## 与电价预测的关系

| 通道 | 主表 | 可选 |
|------|------|------|
| 电价 | `price_tou` | BiLSTM：`obs=price_predicted`，`settle=price_realized` |
| 风光负荷 | perfect | noisy / residual BiLSTM predicted |
