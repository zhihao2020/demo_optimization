# 风光 / 负荷日前信息结构

## 一句话

- **物理真值**：始终由 FMU 内嵌表驱动  
- **策略观测**：默认 **24h 完美日前**（`forecast.mode=perfect`）  
- **可选消融**：`noisy` 乘性误差 + 可选时移，**只改 observation**，不改结算  

这是 **price-taker 厂站调度下的日前预报**，**不是** ISO 出清或完整电力市场交易流程。

## 配置

`src/config/env_config.yaml` → `forecast`：

| 字段 | 含义 |
|------|------|
| `mode` | `perfect`（主表）/ `noisy`（附录消融） |
| `noise.sigma.*` | 各通道乘性相对误差标准差 |
| `noise.seed` | 可复现 |
| `noise.lag_hours` | 预报时移（正=滞后） |

环境构造覆盖：

```python
PowerSystemEnv(forecast_mode="noisy", forecast_noise_seed=0, forecast_noise_sigma=0.10)
```

## 论文表述建议

> The agent observes a 24 h day-ahead forecast of wind speed, irradiance, ambient temperature and load, while the FMU realizes the physical trajectories. In the main experiments the forecast is perfect (consistent with published boundary series). As a robustness study we corrupt the forecast with multiplicative noise (and optional lag), keeping settlement and plant dynamics unchanged. We model a price-taker TOU path and do not simulate ISO market clearing.

## 与电价预测的关系

| 通道 | 主表 | 可选消融 |
|------|------|----------|
| 电价 | `price_tou` 完美分时 | BiLSTM 预测价 obs + 实现价结算 |
| 风光负荷 | perfect DA | noisy DA（本文件） |

二者可叠加，但实验矩阵建议控制在 1–2 个代表场景。
