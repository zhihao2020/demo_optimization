## 数据与预测

```powershell
$env:PYTHONPATH = "src"

# 1) DA 分时 + 残差实现价
python scripts/build_price_residual_series.py

# 2) BiLSTM 预测残差 → data/price_predicted.csv + price_realized.csv
python scripts/train_price_bilstm.py --epochs 20 --device cpu
```

| 文件 | 用途 |
|------|------|
| `data/price_tou.csv` | 山东分时 DA 到户价（默认结算） |
| `data/price_residual_series.csv` | DA / realized / eps |
| `data/price_realized.csv` | 实现价（结算） |
| `data/price_predicted.csv` | BiLSTM 预测价（观测） |
| `data/forecast_models/price_bilstm.pt` | 模型 |

**约定**：观测可用预测价；**结算始终用实现价**（`market.price_path`）。
