## 1. 写作口径（对齐 Cui）

Cui（Energy, GHTD3）是：两条增广 MDP → 层次 TD3 → 历史目标重标 → 三季对照 TD3 / PSO / 二次规划。**不报多种子、不报均值±标准差。**

本文同样：

- 方法名 **HMSD = Hierarchical Multi-energy Safe Dispatch**（主线未开市场先验，不要写成 Market-aware）。
- 主表只放 seed 0。
- 冬、过渡：HMSD 相对扁平 TD3 明显更好（TD3 近乎闲置）。
- **夏季如实写：扁平 TD3 的综合货币更好**。HMSD 电池/火电吞吐更大，外部成本更高。不要写「全面碾压」。
- 不把旧稿里的 MSGP / MS-HER / F-MLE / 5 维目标 / 多种子表写进主线。
- 论文卖点改为：非凸压空问题几何 + 同目标层次 + 季节机制（闲置 / 过循环）。没涨钱的模块不写。

## 3. 机制一句话

| 季节 | 一句话 |
|------|--------|
| 冬 | 层次库存目标让 HMSD 做跨日吞吐；扁平 TD3 闲置，规则/线性规划死守满发火电。 |
| 过渡 | HMSD 仍最能赚钱，期末库存略超门；粒子群现金接近但周未跑满。 |
| 夏 | 好的扁平策略少循环就能赚钱；层次策略过度使用电池与火电。 |

不要把夏季写成「还差一个模块就能全面胜利」。

扁平 TD3 用公平表 `seasonal_v1/winter/td3_s0`（同一协议、同一种子；`ablation_flat_td3_winter_s0` 队列里仍占着一个进程，日志只有启动协议、没有 `train_result`，不必等它才写表）。

对照：公平表主线冬季 HMSD 为 \(R=113.61\)、\(J_{\mathrm{gen}}=1.599\times10^{7}\)，与消融「完整」重跑一致。

写法：

- **层次**才是冬季拉开差距的开关（113 对 −1.3）。
- HER / 拒绝学习在这个冬季 seed 上**不是涨钱模块**；关掉后综合货币略高，库存门仍过。
- 拒绝学习的可见证据是入库条数（约 5 万条），不是更低拒绝率、也不是更高 \(J_{\mathrm{gen}}\)。只过滤时拒绝率仍约 34%，说明安全门还在挡，只是不写回经验。
