## 关键发现（写进 Discussion）

### 1. 电价信息结构 **有影响**

| 季节 | GHTD3 perfect→predicted ΔJ | Hybrid perfect→predicted ΔJ |
|------|---------------------------:|----------------------------:|
| 冬 | ≈ −1.38e6（约 −7.5%） | ≈ −1.38e6 |
| 夏 | ≈ −0.85e6（约 −7.6%） | ≈ −0.83e6 |
| 过渡 | ≈ **+0.90e6**（结算价变实现价后 J 上升） | 类似 |

→ 与既有「预测价观测 / 实现价结算」叙事一致：**电价通道进入决策与结算链路**。

### 2. 资源 perfect / noisy / predicted **闭环指标相同**

对 **已在 perfect 资源预报下训练** 的 GHTD3 / Hybrid，确定性评估时三季 J、reward、SOC **不随 resource_mode 变化**。

可能原因（诚实写）：

1. 策略主要依赖 **当前物理 19 维 + 电价**，对 24h 风光负荷特征不敏感；  
2. 训练分布 = perfect，测试 noisy/predicted 的偏差不足以改变 argmax 动作；  
3. residual 预报误差相对策略分辨率偏小。

**论文写法**：

> Under frozen policies trained with perfect resource forecasts, closed-loop metrics are insensitive to resource-forecast corruption, whereas price-forecast quality shifts weekly cash flow by ~7–8% in winter/summer. This motivates either (i) reporting resource BiLSTM as an offline forecasting module with MAE tables, and/or (ii) future retraining under noisy/predicted resource observations if resource-forecast robustness is a primary claim.
