# Applied Energy 问题深度与贡献钉死（HMSD 主线）

文档更新：2026-08-12

## 1. 科学/工程问题（一句话）

在**非凸压缩空气储能合法集**与**硬安全筛选**下，如何让强化学习在**与扁平方法相同的外在综合经济目标**上，稳定学会跨周库存协调的小时级调度？

## 2. 问题难点（为何不是“再训一个 TD3”）

| 难点 | 含义 | 若不处理会怎样 |
|------|------|----------------|
| D1 非凸动作 | 压空指令合法集为断开三段，Box 连续会进非法区 | 无效吞吐 / 仿真失败 / 学偏 |
| D2 硬安全 | 可行域与锁机约束下，提议动作大量被拒 | 有效样本稀疏，扁平策略不稳定 |
| D3 长时域经济 | 168 小时套利与库存耦合，奖励延迟 | 短视充放，期末库存差 |
| D4 信息结构 | 日前序列进观测、实现价结算 | 预报—执行偏差（可选加深实验） |

主线协议为公平对比固定：低层优化环境外在奖励 \(r^{\mathrm{ext}}\)（与扁平 TD3 同目标），从而**隔离“层次结构是否提供有效归纳偏置”**这一可检验问题。

## 3. 方法回答（HMSD 最小充分机制）

1. **目标条件层次**：高层每 \(c=8\) 步输出二维库存增量子目标；低层在 \((s,g)\) 下输出设备指令。  
2. **非凸压空连续表示**：策略连续标量经合法投影/映射进入仿真（`caes_u`），问题仍非凸，但可被确定性策略参数化。  
3. **安全筛选 + 拒绝样本学习**：非法/危险提议不进主仿真；拒绝转移以约束型负奖励自环进入低层经验池。  
4. **历史目标重标**：提高子目标相关样本利用率。  

可选模块（非 fair 主线默认）：市场目标先验、回收目标强化、规则预热——用于敏感性/扩展，不充当“未开却声称”的贡献。

## 4. 可投稿的三条贡献（建议定稿文案）

**C1（问题）** 建立风光–火电–电池–压空系统在硬安全与非凸动作下的综合经济调度学习问题，并给出与扁平强化学习同目标的公平季节评估协议。  

**C2（方法）** 提出目标条件层次安全调度方法 HMSD：库存子目标分解长时域协调，连续压空表示 + 安全拒绝学习缓解有效样本稀疏。  

**C3（实证）** 在冬/过渡/夏留出周、多种子对比中，HMSD 相对扁平 TD3 在多数季节具有更高且更稳的综合经济指标，并分析安全拒绝与失败模式。

## 5. 可证伪命题（指导实验）

| 命题 | 验证 |
|------|------|
| P1 层次有用 | 同目标下 HMSD 优于扁平 TD3（主表） |
| P2 拒绝学习有用 | 关 `learn_from_reject` 拒绝率降得慢或经济变差（消融） |
| P3 目标重标有用 | 关 HER 学习曲线/终绩变差（消融） |
| P4 安全必要 | 无安全时硬违规或训练崩溃（谨慎仿真） |

## 6. 与“深度不足”的对应

- 深度来自 **D1–D3 的耦合**，不是更大网络。  
- 主结果应回答 P1–P3；市场先验等仅作扩展。
