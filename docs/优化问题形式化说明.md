# 多能流系统运营优化问题：形式化说明

> 对应论文 **§III Market-Oriented Operation Problem**。  
> 物理对象：Modelica 多能流（风光火 + 电池 + CAES）经 FMU 联仿；市场：**price-taker 分时电价**，不做 ISO 出清。

---

## 1. 问题定义（一句话）

在 **外生分时购售电价** 与 **高保真 FMU 动力学** 下，逐小时选择 **混合调度指令**，最大化运营期 **净现金流**（或等价最小化运行成本），并满足设备、电网接口、储能 SOC 与 CAES **非凸可运行域** 约束。

---

## 2. 决策变量（Decision Variables）

### 2.1 每步混合动作 \(a_t\)

策略 / 优化器 / 群智能在时刻 \(t\) 输出：

\[
a_t=\big(u_t^{\mathrm{tp}},\; u_t^{\mathrm{bat}},\; m_t^{\mathrm{caes}},\; \mu_t^{\mathrm{caes}}\big)
\]

| 符号 | 代码/FMU | 含义 | 取值域 |
|------|----------|------|--------|
| \(u_t^{\mathrm{tp}}\) | `u_tp` | 火电调度指令（相对额定） | \([u_{\min}^{\mathrm{tp}},1]\)，约 \([1/3,1]\)（\(P_{\min}/P_{\mathrm{cap}}\)） |
| \(u_t^{\mathrm{bat}}\) | `u_battery` | 电池指令 | \([-1,1]\)（实现中负放正充，再投影到**动态**界） |
| \(m_t^{\mathrm{caes}}\) | `caes_mode` | CAES 模式 | \(\{\mathrm{DISCHARGE}=0,\;\mathrm{IDLE}=1,\;\mathrm{CHARGE}=2\}\) |
| \(\mu_t^{\mathrm{caes}}\) | `caes_magnitude` | CAES 幅值 | \([0,1]\)；IDLE 时为 0 |

解码为 FMU 标量输入 \(u_t^{\mathrm{caes}}\) 时，合法集为 **非凸**：

\[
u^{\mathrm{caes}}\in[-1,-0.33]\cup\{0\}\cup[0.86,1]
\]

（最小启机/工况约束，见 `src/config/env_config.yaml` → `actions.u_caes.valid_intervals`。）

### 2.2 状态变量 \(x_t\)（由 FMU 演化，不可直接优化）

| 类别 | 变量（观测名） |
|------|----------------|
| 储能 SOC | `battery_soc`, `caes_gas_soc`, `caes_hot_soc`, `caes_cold_soc` |
| 热力 | `caes_gas_pressure/temperature`, `caes_hot/cold_temperature` |
| 功率 | `p_thermal`, `p_battery`, `p_caes`, `p_grid`, `p_wind_*`, `p_pv_*`, `p_load_actual`, `p_curtailment`, `p_unserved` |
| 外生信息 | 24h 日前预报（风/辐照/温/负荷）；分时 \(\lambda_t^{\mathrm{buy}},\lambda_t^{\mathrm{sell}}\) |

### 2.3 时间尺度

| 量 | 取值 |
|----|------|
| 决策/通信步长 \(\Delta t\) | 1 h |
| 周优化时域 \(T\) | 168 步 |
| 全年评价 | 53 个周窗覆盖 8760 h（每窗 reset，**非**连续年 SOC） |

---

## 3. 优化目标（Objective）

### 3.1 论文主目标（报告用 KPI，与训练 reward 分离）

最大化周（或年窗合计）**净运营现金流增量**：

\[
\max_{\{a_t\}_{t=0}^{T-1}}
\;
J
=
\sum_{t=0}^{T-1}
\Delta \mathrm{CF}_t^{\mathrm{sys}}
\]

等价地最小化运行成本：

\[
\min \; C^{\mathrm{sys}}=\sum_{t=0}^{T-1}\big(-\Delta \mathrm{CF}_t^{\mathrm{sys}}\big)
\]

**现金流构成**：

1. FMU 输出累计经济量差分：`economic_cashflow_*`（风/光/火/电池/CAES/负荷/电网）。  
2. **Market 模式**下电网项用分时电价 **Python 结算替换** FMU 常数购售价增量：

\[
\Delta \mathrm{CF}_t^{\mathrm{sys}}
=
\big(\Delta \mathrm{CF}_t^{\mathrm{FMU,total}}
-
\Delta \mathrm{CF}_t^{\mathrm{FMU,grid}}\big)
+
\mathrm{CF}_t^{\mathrm{mkt}}\!\big(p_t^{\mathrm{grid}},\lambda_t^{\mathrm{buy}},\lambda_t^{\mathrm{sell}}\big)
\]

实现：`src/envs/reward_calculator.py` + `src/market/settlement.py`。

### 3.2 强化学习训练用代理目标（不作为论文主表唯一数字）

\[
r_t
=
\underbrace{\frac{\Delta \mathrm{CF}_t^{\mathrm{sys}}}{C_{\mathrm{ref}}}}_{\text{经济}}
+
\underbrace{r_t^{\mathrm{SOC\,shape}}}_{\text{过程 shaping}}
+
\underbrace{b_{\mathrm{SOC}}}_{\text{仅期末}}
\]

| 项 | 说明 |
|----|------|
| \(C_{\mathrm{ref}}\) | 成本归一参考（规则季节 P95，约 \(1.565\times 10^5\) CNY/step） |
| \(r_t^{\mathrm{SOC\,shape}}\) | 相对初始 SOC 的 L1 势/绝对值惩罚，末段加强 |
| \(b_{\mathrm{SOC}}\) | 期末 **能量 SOC**（battery + gas）达标 bonus / 未达标 L1 罚 |
| GiveSafe 拒绝 | **不推进 FMU**，不进经济 PhysicalReplay |

### 3.3 论文结果表建议 KPI

| KPI | 含义 | 代码/指标 |
|-----|------|-----------|
| \(J\) | 净现金流 | \(\sum\) `economic_cashflow_delta` |
| \(E^{\mathrm{curt}}\) | 弃风弃光能量 | `curtailment_energy_mwh` |
| \(E^{\mathrm{uns}}\) | 缺供能量 | `unserved_energy_mwh` |
| 火电电量 | 化石出力 | `thermal_generation_mwh` |
| 储能吞吐 | 调度活跃度 | `battery_throughput_mwh`, `caes_throughput_mwh` |
| 购售电 | 市场参与 | `market_buy_cost`, `market_sell_revenue`, 能量 MWh |
| 期末能量 SOC | 运营回收 | energy L1 ≤ \(\tau\)（`primary_keys`） |
| 安全 | 可运行性 | 硬违反、GiveSafe 拒绝、FMU 失败 |
| 计算成本 | 公平对比 | 墙钟时间、FMU `step` 次数 |

相对 **原始运行 B0**（保守规则）的变化：

\[
\Delta J=J-J_{B0},\quad
\Delta E^{\mathrm{curt}}=E^{\mathrm{curt}}-E^{\mathrm{curt}}_{B0},\quad
\text{火电比}=\frac{E^{\mathrm{th}}}{E^{\mathrm{th}}_{B0}},\quad
\text{吞吐比}=\frac{\mathrm{Thr}}{\mathrm{Thr}_{B0}+\varepsilon}
\]

## 4. 约束（Constraints）

### 4.1 动力学约束（隐式，FMU 黑盒）

\[
x_{t+1}=f_{\mathrm{FMU}}(x_t,\,a_t^{\mathrm{phys}},\,w_t)
\]

- \(a_t^{\mathrm{phys}}\)：混合动作解码后的 FMU 输入  
- \(w_t\)：模型内嵌 8760 风光负荷边界  
- **无解析梯度** → 适合 RL / 群智能 / 仿真滚动优化  

### 4.2 动作与动态可行域（执行前 Oracle）

| 约束 | 说明 |
|------|------|
| 火电界 | \(u_t^{\mathrm{tp}}\in[u_{\min,t}^{\mathrm{tp}},u_{\max,t}^{\mathrm{tp}}]\)（含爬坡相关动态界） |
| 电池界 | \(u_t^{\mathrm{bat}}\in[u_{\min,t}^{\mathrm{bat}},u_{\max,t}^{\mathrm{bat}}]\)（SOC 相关） |
| CAES 模式掩码 | 当前状态允许的 charge/idle/discharge |
| CAES 合法 \(u^{\mathrm{caes}}\) | 非凸区间 + 最小运行/锁定步 |
| 预检可执行 | `FeasibilityOracle.check_action_executable` |

### 4.3 硬安全（违反则拒绝或终止）

- 电网接口/容量类限制  
- 火电爬坡  
- SOC / CAES 禁区与热力状态  
- 非有限输出（NaN/Inf）  
- GiveSafe：不安全动作 **不调用** 主 FMU  

### 4.4 运营期末（能量库存）

\[
e_{L1}^{\mathrm{energy}}
=
w_{\mathrm{bat}}|\mathrm{SOC}_{\mathrm{bat},T}-\mathrm{SOC}_{\mathrm{bat},0}|
+
w_{\mathrm{gas}}|\mathrm{SOC}_{\mathrm{gas},T}-\mathrm{SOC}_{\mathrm{gas},0}|
\le \tau
\]

- 主达标：`primary_keys = [battery_soc, caes_gas_soc]`，\(\tau=0.06\)  
- 热/冷罐：进入 shaping 与诊断，不作为否决主 KPI（Discussion 可报）  
- 环境硬回收：末 \(H\) 小时对 battery/gas 动作扭矩  

### 4.5 市场假设（建模约束）

- **Price-taker**：\(\lambda_t\) 外生，调度不反馈改价  
- **无网络出清**：不建 SCUC/SCED/LMP  

---

## 5. 三种求解范式

| 范式 | 数学形态 | 与 FMU 关系 |
|------|----------|-------------|
| **运筹滚动 LP/MILP（松弛）** | 每步 \(\min c^\top z\) s.t. 线性功率平衡+SOC；CAES 松弛 | 求解器用**代理模型**；仅执行第一步再 **真实 FMU step** |
| **群智能 PSO** | \(\max_\theta F(\theta)\)，\(F\) 为整周滚仿真净现金流等 | 每个粒子评价 = **1 次完整 168h FMU 轨迹** |
| **RL（Hybrid / GHTD3 / SAC）** | \(\max_\pi\mathbb{E}[\sum_t \gamma^t r_t]\) | 逐步 `propose → GiveSafe → FMU.step`，经验更新 |

**公平性**：所有方法最终指标均在 **同一 FMU 轨迹** 上统计；报告 FMU 调用次数与墙钟时间。

## 6. “模型原始结果”定义

| ID | 名称 | 含义 |
|----|------|------|
| **B0** | 原始/保守运行 | `RuleBasedController`：高火电 + 储能 idle（**无智能优化**） |
| **B1** | 峰谷规则 | 价格阈值套利（工程启发式） |

对比时 B0 为“模型按默认保守策略运行”的基线，而非未初始化的空仿真。
