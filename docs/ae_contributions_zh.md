# 贡献口径：原理 / 微创新 / 迁移

日期：2026-08-14

Applied Energy 不要求全新算法家族。认三类：

1. **迁移**  
   把 Cui 的目标条件层次从氢能综合能源迁到风光—火电—电池—压空仿真模型；合法集断开、分时电价 + 碳价 + 库存门。对象变了，不是换皮名词。

2. **微创新**  
   低层奖励改成与扁平方法同一笔综合货币。就改一条方程，但对照因此成立。  
   预算维（放电 / 超额火电）是同一原理的延伸：高层动作要对应目标函数里的磨损与燃料，不是再叠回放。

3. **贴原理**  
   子目标只有「库存往哪走」，没有磨损坐标 → 冬修闲置、夏过循环。这是定义推出来的，不是调参故事。

不写：比 Cui 分数高、全新演员、没涨的模块清单。
