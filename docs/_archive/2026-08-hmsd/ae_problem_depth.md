# Applied Energy 问题深度（扁平混合 SAC 主线）

文档更新：2026-08-19

## 1. 科学/工程问题（一句话）

在 Sysplorer FMU 上，压空指令是状态依赖的断开合法集 `(mode, magnitude)`。如何让闭环调度尊重该合法集，在无 fallback 时跑完一周，并优化 TOU 现金 + ETS 碳 + 弃电/缺电 + 电池磨损？

## 2. 问题难点

| 难点 | 含义 | 若不处理会怎样 |
|------|------|----------------|
| D1 非凸动作 | 合法集 `[-1,-0.33]∪{0}∪[0.86,1]`，连续投影会把意图静音到 idle | abort / 学偏 idle |
| D2 状态依赖模式 | 锁机、最短运行、气压/热罐收缩 `F(s)` | 非法模式被拒，有效样本稀疏 |
| D3 长时域经济 | 168 h 套利与库存耦合 | 短视充放 |
| D4 孪生 ≠ 凸代理 | LP 可在简化模型上可行 | 同一周在 FMU 上崩或非法 |

## 3. 方法回答

1. 扁平混合 SAC：模式分类头 + 幅值头，`mode_mask` 置 `-inf`。  
2. GiveSafe 硬筛选；拒绝样本进回放。  
3. 投影 SAC / 滚动 LP 作对照，不把分层当默认身份。

## 4. 贡献

**C1（对象）** 高保真火电–电池–压空 FMU 上的周调度：断开合法集、碳价、软库存奖励。  
**C2（求解器）** 参数化混合动作 SAC，使策略在合法模式里动作而不是投影静音。  
**C3（实证）** 相对投影 SAC 的 abort、相对凸代理的孪生缺口、跑完周比例与模式足迹。
