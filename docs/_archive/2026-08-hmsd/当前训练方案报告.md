# 当前训练方案报告

文档更新：2026-08-14 16:10 (+08:00)

## 1. 概述

本方案针对**风光火储综合能源系统**的**小时级经济调度**问题。决策周期为一小时，单次学习回合覆盖一周（一百六十八小时）。

执行的是**分季节公平对比**训练：冬、过渡、夏三季各自训练与评估；强化学习方法与基线共用同一套环境奖励与周协议，便于横向比较。

---

## 2. 优化目标

### 2.1 主目标

在可行与安全约束下，**最大化**一周内的**期望综合经济回报**。

逐步奖励以「综合货币增量 / 标定参考成本」为主。权威经济层（配置中的综合目标方案）定义为：

\[
\Delta J_{\mathrm{gen}}
=
\Delta J_{\mathrm{cash}}
-
\pi\cdot\Delta m_{\mathrm{CO_2}}
-
C^{\mathrm{CUT}}
-
C^{\mathrm{deg}}
\]

\[
r_t^{\mathrm{eco}}
=
\frac{\Delta J_{\mathrm{gen}}}{C_{\mathrm{ref}}}
\]

单步总奖励：

\[
r_t
=
r_t^{\mathrm{eco}}
+
r_t^{\mathrm{shape}}
+
r_t^{\mathrm{term}}
\]

其中终端项 \(r_t^{\mathrm{term}}\) 仅在回合最后一步（且完整无失败）计入。

分项含义：

1. **经营性现金流增量** \(\Delta J_{\mathrm{cash}}\)：仿真模型内设备侧累计现金流差分；开启分时电价市场时，**电网项**由 Python 侧按购售电价与联络线功率重算后替换模型内电网增量。
2. **碳排放相关成本** \(\pi\cdot\Delta m_{\mathrm{CO_2}}\)：火电与（仅计）购电对应的二氧化碳质量 × 碳价。
3. **弃电与缺供电惩罚** \(C^{\mathrm{CUT}}\)：按弃电能量与未供电能量分别计价。
4. **电池退化** \(C^{\mathrm{deg}}\)：仅计放电能量累计 \(\delta\) 的凸代价差分（见下表）。

此外还有：

- **运行过程中的荷电状态塑造** \(r_t^{\mathrm{shape}}\)（引导周中库存不过度漂移）；
- **回合结束时**电池与气库荷电状态相对初值的达标奖励或未达标惩罚。

### 2.2 约束与安全

优化在硬约束下进行，约束**不**通过简单加大惩罚项替代：

- 火电爬坡与出力上下限、电池与压缩空气储能运行边界；
- 压缩空气储能合法指令集合（非凸）；
- **安全动作筛选**：候选动作经可行性判定（及可选影子仿真）后，仅安全动作推进主仿真；
- 被拒绝动作可写入经验池，以**负的约束型奖励**与状态自环形式参与学习，避免「只拒绝不更新策略」。

### 2.3 评估目标

训练完成后，在各季节**留出评估周**上统计：

- 综合现金流或综合货币增量；
- 缺供电、吞吐、火电发电量等运行指标；
- 期末荷电状态是否满足约定容差。

对比时以同一评估周、同一奖励定义为准。

## 3. 用到的算法与方法

### 3.1 主方法

**HMSD（Hierarchical Market-aware Safe Dispatch，层次化市场感知安全调度）**

实现上采用**目标条件层次结构 + 双延迟深度确定性策略梯度**（低层与单层 TD3 同族）：高层给出有界库存子目标，低层在「观测 + 子目标」下输出设备指令；执行经安全筛选；公平对比配置下低层直接优化环境外在经济奖励（与扁平 TD3 目标对齐），并可用历史目标重标提高样本效率。

- 高层目标

| 变量 | 含义 | 更新频率 |
|------|------|----------|
| 电池荷电变化 \(\Delta\mathrm{bat}\) | 未来若干步希望达到的电池荷电状态增量 | 默认每八小时更新一次 |
| 气库荷电变化 \(\Delta\mathrm{gas}\) | 未来若干步希望达到的气库荷电状态增量 | 默认每八小时更新一次 |

- 低层策略：输出火电、电池与压缩空气储能指令。

| 变量 | 含义 | 取值说明 |
|------|------|----------|
| 火电指令 \(u_{\mathrm{tp}}\) | 火电机组出力指令 | 连续，落在机组允许的最小到最大出力区间 |
| 电池指令 \(u_{\mathrm{battery}}\) | 蓄电池充放电指令 | 连续，有符号：正负表示充放方向与强度 |
| 压缩空气储能指令 \(u_{\mathrm{caes}}\) | 压缩空气储能运行指令 | 策略侧可用连续标量表示，再映射为**放电 / 待机 / 充电**及该模式下的强度；物理合法集合为非凸三段区间 |

说明：压缩空气储能不能在非法中间区段任意取值；连续表示仅便于策略学习，真正执行时再映射。

### 3.2 对比基线

| 方法 | 说明 |
|------|------|
| **粒子群优化（Particle Swarm Optimization）** | 在低维参数化调度策略空间搜索；每个粒子用完整一周物理仿真评价 |
| **滚动线性规划** | 松弛代理模型上的滚动时域线性规划，只执行第一步并接入真仿真 |
| **TD3（Twin Delayed Deep Deterministic Policy Gradient，双延迟深度确定性策略梯度）** | 单层确定性策略，无高层子目标；安全筛选与环境相同 |
| **SAC（Soft Actor-Critic，柔性演员—评论家）** | 单层最大熵随机策略基线，对照探索方式差异 |

#### 3.2.1 粒子群优化原理（与本仓库实现一致）

- **优化对象**：六维参数 \(\theta\)，编码「峰谷价阈值 + 电池/压空参与强度 + 火电偏置 + 期末回收强度」，再实例化为可逐步执行的参数化策略（非直接优化全部 168 步原始动作）。
- **群体更新**（标准形式）：每个粒子维护位置与速度；速度由惯性项、个体历史最优、全局最优三部分加权得到（默认惯性 0.6，个体/社会系数均为 1.4），位置在搜索边界内更新。
- **适应度**：对 \(\theta\) 在指定评估周起点跑满一周真仿真，得到经济与约束相关指标；缺供电、仿真失败、期末荷电偏离等以加权惩罚进入适应度（实现中有较大失败/荷电惩罚系数），使搜索偏向「能跑完且库存可接受」的参数。
- **默认规模**：约 12 个粒子、25 轮迭代（任务脚本可覆盖）；评价昂贵（每评价一周仿真），故维度刻意保持较低。
- **定位**：开环/参数搜索基线，**不**在线做时序策略梯度。

#### 3.2.2 滚动线性规划原理（与本仓库实现一致）

- **是什么**：每决策步在**代理线性模型**上求解短时域线性规划（`scipy.optimize.linprog`），**只执行第一步**动作，再经解码进入**真实**物理仿真推进一步；下一步根据新状态重新求解。这是经典滚动时域控制（模型预测控制的线性特例），**不是**对整周做一次全局精确最优。
- **代理决策变量（功率级）**：火电、电池充/放、气库等效充/放、购/售电、弃风弃光、缺供。压缩空气在代理中连续松弛，执行时再落到合法三段；小功率走待机。
- **代理约束**：功率平衡（风光按发电为负瓦折成正注入）、电池与气库荷电动态与容量、联络线、火电逐步爬坡。负荷/风/光用日前表做 24 小时形状，电价按未来时刻读取。
- **代理目标**：对齐综合收益的线性近似——购售电 + 燃料 + 碳 + 弃电/缺供 + 电池放电磨损 + 周末库存绝对值软罚。**不再**在最后 40 小时强行抬火电。
- **与真机关系**：代理只负责「算一步意图」；权威账仍是真仿真。可复现的优化型对照，**不是**同一模型下的全局最优上界。

#### 3.2.3 SAC 算法原理（与本仓库实现一致）

- **目标**：在期望回报之外同时最大化策略熵，鼓励随机探索、减轻过早收敛到次优确定性行为。
- **结构**：随机演员网络输出动作分布；双评论家估计状态—动作价值；目标网络缓慢跟踪；温度参数 \(\alpha\) **可学习**（默认目标熵约 \(-3\)，对应三维连续动作尺度）。
- **本仓库动作**：连续三维物理指令（火电、电池、压缩空气）；经安全筛选后写入混合安全经验池再更新。
- **与 TD3 对照**：TD3 为确定性演员 + 目标策略噪声；SAC 为最大熵随机演员。二者同为单层、无 HMSD 高层子目标。
