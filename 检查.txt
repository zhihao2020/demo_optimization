## 先说 PSO：这个 week 25 的问题很好修

你描述的失败和最新代码完全对应。

当前 `ParametricPricePolicy.predict()` 是：

```python
u_bat = 0.0
```

只有触发：

* recovery；
* low-price charge；
* high-price discharge；

时才执行：

```python
np.clip(..., feas.u_battery_low, feas.u_battery_high)
```

但如果电价落在中间区间，`u_bat` 就一直保持 0，最后直接：

```python
return physical_dict(
    float(np.clip(u_tp, lo, hi)),
    float(u_bat),
    ...
)
```

也就是说，当 Oracle 给出：

$$
u_{\mathrm{battery}}\in[0.013,1]
$$

时，PSO 仍发送：

$$
u_{\mathrm{battery}}=0
$$

这就是 week 25 第 93 h 的直接原因。最新 commit 只补了 **CAES mode mask feasibility**，并没有补 battery 的最终动态可行域映射。

所以这里应该直接改成最终统一收口：

```python
u_bat = float(
    np.clip(
        u_bat,
        float(feas.u_battery_low),
        float(feas.u_battery_high),
    )
)
```

然后再 `physical_dict()`。

这不是为了让 PSO“作弊”，而是修复它现在明显不完整的 action adapter。因为同一个 policy 已经对：

* Thermal：动态 `[lo, hi]` clip；
* CAES：根据 `mode_mask` + `u_from_mode_mag_feasible()` 映射；

做了动态可行化。只留下 Battery 不映射，本身就是实现不对称。

**我建议现在马上修这个，然后重跑 PSO 25 → 38 → 51。**

week 12 的：

$$
CC=-13.91M
$$

可以保留，但最好最终四周都用**同一个修复后的代码版本**重新跑；如果时间实在不够，至少确认修复不会改变 week12 trajectory。

# PSO 还有一个论文方法学问题需要马上改文字

最新代码现在的 PSO 是：

```python
run_pso(start_time=start)
```

即在**每一个 final holdout week 本身**执行：

$$
12\ particles\times25\ iterations
$$

每个粒子直接完整滚一周 FMU，然后取该周最好的 \(\theta\)。

这意味着它严格来说不是：

> “trained on TRAIN weeks and generalized to held-out week”

而是：

> **直接在该测试周上进行 FMU-based direct search。**

所以不能和 PC-HybridTD3 一起描述成：

> four held-out policies

PSO 应该叫：

> **week-wise FMU-based parametric PSO benchmark**

甚至可以把它解释成一个很强的 baseline：

$$
\theta_w^*
=
\arg\min_\theta CC_w(\theta),
$$

即它实际上针对每一个测试周都重新搜索，而 PC-HybridTD3 是一次训练后直接部署。

这对你反而有利。

但要把成本报告出来。

不能只报告 PSO 最后：

$$
\text{policy inference time}
$$

却把：

$$
12\times25\times168
\approx 50\,400
$$

次 FMU steps 的 search cost 完全藏掉。

最新稿甚至写了：

> Table reports subsequent one-step decision time, not the search.

这个需要加一句：

> PSO search time is reported separately because its parameters are re-optimized for each evaluation week.

最好新增列：

| Method       | Online ms/step | Offline/Search time |
| ------------ | -------------: | ------------------: |
| Rule         |           0.76 |                   – |
| MILP         |            225 |                   – |
| PSO          |              x |         xx min/week |
| PC-HybridTD3 |            3.8 |    training offline |

否则 reviewer 会觉得 runtime comparison 不公平。
